# Shri Haridutt Ayurvedic Medical College & Hospital
### Vedic Heritage × Modern Academic Luxury — Official Institutional Platform & CMS

---

## 🏛️ Executive Overview
A production-ready institutional digital ecosystem designed for **Shri Haridutt Ayurvedic Medical College & Hospital** (NCISM Approved • Ministry of AYUSH, Govt. of India). 

Developed with a design philosophy of **Vedic Heritage × Modern Academic Luxury**, balancing ancient Indian healing traditions (Brihat Trayi, Charaka & Sushruta Samhitas) with contemporary medical education, hospital bedside clinical rigour, and transparent online admissions.

## 🛠️ Technology Stack
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript 5.7+
- **Styling**: Tailwind CSS with custom Ayurvedic Luxury Palette & Lucide Icons
- **Database & ORM**: Prisma ORM with SQLite (local zero-config default) & Hostinger MySQL compatible
- **Authentication**: JWT session tokens with HTTP-Only secure cookies and Bcrypt password hashing
- **SEO & AEO**: Dynamic `/sitemap.xml`, `/robots.txt`, JSON-LD `EducationalOrganization` schema, OpenGraph metadata.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Push database schema & seed initial data
npx prisma db push
node prisma/seed.mjs

# 3. Start development server
npm run dev
```

Platform opens at `http://localhost:3000`.
